# Sample data

Every file below is synthetic: invented clinical notes and the tables derived from them,
generated by [`generate_sample.py`](generate_sample.py) from sentence templates and a small
vocabulary of problems, with twelve short notes written by hand. No real patient, note or
record is used. Licence: CC0-1.0. The folder is about 200 KB, far under the 5 MB per file
and 20 MB per folder limits.

| File | What it is | Where it came from | Licence | Synthetic |
| --- | --- | --- | --- | --- |
| `notes_raw.parquet` | 222 rows of clinical notes for 150 patients: note_id, patient_id, text. Five rows lack an id or the text | Generated by `generate_sample.py` | CC0-1.0 | yes |
| `notes.parquet` | The 217 notes that carry both identifiers and text | `prepare_notes` | CC0-1.0 | yes |
| `patient_status.parquet` | Administrative status per patient: eligibility, orec, medicaid | Generated by `generate_sample.py` | CC0-1.0 | yes |
| `hcc_weights.parquet` | The HCC weights used by the simplified risk model: hcc, hcc_name, weight | From `raf.py` | CC0-1.0 | yes |
| `icd10_codes.parquet` | 646 coded problems per note with HCC and assertion status | `extract_icd10` | CC0-1.0 | yes |
| `demographics.parquet` | Inferred gender at birth and age per patient | `infer_demographics` | CC0-1.0 | yes |
| `patient_profiles.parquet` | Demographics, administrative status and the counted HCCs per patient | `build_patient_profiles` | CC0-1.0 | yes |
| `patient_risk.parquet` | Demographic weight, HCC weight and risk score per patient | `calculate_raf` | CC0-1.0 | yes |
| `raf_bands.parquet` | Patient counts and average risk score per risk band | `raf_summary` | CC0-1.0 | yes |
| `hcc_distribution.parquet` | Patient counts and weights per HCC | `hcc_distribution` | CC0-1.0 | yes |
| `graph_nodes.parquet` | 184 knowledge-graph nodes (150 Patient, 27 Condition, 7 HCC), one row per node | `build_knowledge_graph` | CC0-1.0 | yes |
| `graph_edges.parquet` | 663 knowledge-graph edges, one fact per row, with note evidence and character span | `build_knowledge_graph` | CC0-1.0 | yes |

`icd10_codes` and `demographics` are what a text model would return for each note. Here they
are exact by construction, because they come from the same templates as the notes; they are
not the output of a model. `tests/recorded_answers.json` replays them so the two model jobs
run without a model. Every other derived table is made by the repository's own jobs from
these, so nothing is rejected.

The 217 notes belong to 150 patients, 67 of whom have two notes. The first twelve notes
(patients p001 to p012) are hand-written and kept word for word. Each note states the
patient's age and sex in prose, and names problems with every assertion status: present,
past, family, absent, possible, hypothetical and conditional. Five rows of `notes_raw` have a
missing or empty note id, patient id or text, so `prepare_notes` has rows to drop.

The notes cover the four HCCs whose weights the simplified model has: HCC 18 (diabetes with
chronic complications, 0.625), HCC 19 (diabetes without complication, 0.124), HCC 35
(inflammatory bowel disease, 0.279) and HCC 40 (rheumatoid arthritis, 0.423). They also name
problems with no HCC (hypertension, hyperlipidaemia, osteoarthritis, hypothyroidism and
reflux) and problems that map to HCC numbers outside the model: heart failure (85), atrial
fibrillation (96) and chronic obstructive pulmonary disease (111), in the CMS-HCC version 24
numbering as the generator's author knows it. These rows carry their HCC number and a weight
of 0 in the simplified model. Past, family, absent, possible, hypothetical and conditional
problems are in `icd10_codes` too and are left out of `patient_profiles`.

The ICD-10-CM codes are real, public codes with descriptions written from memory; they are
not checked against the current release of the code set. The risk adjustment factor is a
**simplified** calculation: four example HCC weights, and an age and sex table whose female
70 to 74 cell (0.346) is the one published value and whose other cells are illustrative. It
is not the official CMS-HCC model, which has many more HCCs, disease hierarchies,
interactions and a normalisation factor. Its mapping tables are public and are not included.

To regenerate (the same seed always gives the same files):

```
uv run python data/generate_sample.py
```
